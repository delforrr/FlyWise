- [ ] Cada disparo programado resuelve el último mes cerrado y guarda su alcance; cambio de mes/año avanza el período y una carga manual conserva su mes explícito.
- [ ] Reintentar una ejecución anterior conserva el período capturado originalmente, aunque el calendario haya cambiado.

- [ ] Editar/pausar/reiniciar no duplica schedulers
- [ ] dos disparos incompatibles no publican simultáneamente
